# Travel Easy - C++ Travel Management System

A **C++** project to manage **travel packages** across different locations in India, allowing users to view packages, calculate travel costs, and find the shortest paths between destinations. This system also provides an **admin portal** for managing locations, edges, and packages.

## Features
- **Admin Portal**:  
  - Add/edit/remove locations and travel packages.  
  - Create and manage connections (edges) between locations.  
  - Set and update travel package details (cost, locations).
  
- **Customer Portal**:  
  - View available travel packages.  
  - Calculate travel costs based on selected locations.  
  - Find the shortest path between two locations using **Dijkstra's Algorithm**.

- **User Interface**:  
  - Console-based UI for both admin and customer portals, ensuring ease of use.
  - Well-structured output for clear visualization.

## Technologies Used  
- **C++** – Core programming language for implementation.  
- **Dijkstra's Algorithm** – Used for finding the shortest path between locations.  
- **Standard Template Library (STL)** – Utilized for arrays, vectors, and string manipulations.
